CloudFlow HR

Cel aplikacji

Aplikacja kadrowo‑płacowa działająca w pełni w chmurze, łącząca wygodę Blazor WebAssembly z wydajnością SSR (Blazor Server) dla płynnego UX i krótkiego czasu odpowiedzi. Umożliwia obsługę pełnego cyklu HR: kartoteki pracowników, urlopy, rekrutacje, analitykę KPI oraz integracje z zewnętrznymi systemami.

Technologie

C# ASP.NET Core Blazor WASM Blazor Server Entity Framework SQL

Plan rozwoju

  • Import danych
  • Analityka KPI
  • Automatyzacja procesów
